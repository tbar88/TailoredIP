# State directory

`state/` is the canonical business-state tree for the orchestration layer. Keep these files concise, version-controlled, and aligned with the workstream-specific instructions in `.github/instructions/`.

- Repo files are authoritative.
- Copilot Spaces should mirror, not replace, these files.
- Use `state/00_command_center/current-command-center.md` for the current operating summary.
- Move completed or inactive records into `state/11_archive/` instead of deleting history.
